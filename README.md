# Population Data Sheet downloads

Public download mirror for source data supplied by the United Nations Economic and Social Commission for Asia and the Pacific (UN ESCAP) for the Population Data Sheet dashboards.

This repository is maintained by Nuttapong Buttprom. It is not an official UN ESCAP repository or publication. UN ESCAP is the data source; this mirror does not claim authorship of the data.

## 2026 data

[Download the complete raw CSV](https://github.com/Kokoabassplayer/unescap-population-data/releases/download/2026-v1/Population%20datasheet%202026_for%20Tableau_revised_2026-08-24.csv)

[Release details and checksum](https://github.com/Kokoabassplayer/unescap-population-data/releases/tag/2026-v1)

- Source revision received on 24 August 2026.
- 19,840 data rows, 10 columns, 64 country/area and regional labels.
- All supplied years and indicators are included, independently of dashboard filters.
- The CSV preserves the supplied file bytes, values, units, definitions, formatting, and 387 blank Value cells. Blank is not zero.
- UTF-8 with a byte-order mark and original line endings. Spreadsheet applications can import this CSV.
- Migration-count units in this revision are `number of persons`.
- Only the revised CSV was supplied for this correction. An older Excel file is not distributed as an equivalent version, and no converted Excel file is presented as a UN original.

## Versioning

Dashboard links point to a specific release, not `latest`. New years and corrections receive new releases. Previously distributed files are retained so users can identify the data version they downloaded.

The source's ownership and any applicable source terms remain unchanged. This mirror does not grant a new data license.
